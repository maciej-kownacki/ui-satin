Grouped table (`@uisatin/pro/table-pro`): `TableGrouped` is Table with rows that open onto sub-rows (`getSubRows`, `expanded`), groups with a header, a count and subtotals (`groupBy`, `groupOrder`, `renderGroup`, `collapsedGroups`), columns that `format` and `aggregate` their numbers, a totals row in a `tfoot` (`footer`), a pinned first column with a shadow (`pinned="start"`) and `density="compact"`. With sub-rows or groups it is a treegrid with arrow-key row navigation. Part: `TableRowToggle`. New labels `tableRowsUnder`, `tableGroupCount`, `tableSelectGroup`.
