Agent action log (`@uisatin/pro/agent-undo-log`), an AI pattern for undo over confirm, made for coding agents first: `<AgentActionLog runs onRevert onRevertRun onRestore />` lists what an agent did, run by run, with a Revert on every action. A run is `{ id, label, at, actions }` on a rail like Thinking's steps, its header counting the actions and the lines added and removed. An action is one line (`label` "Edited", `target` in mono, `added` / `removed` in green and red) with a quiet Revert icon button and a tooltip; one that can't be reverted (`revertible: false`, a push) shows a lock and says why (`reason`). While `onRevert`'s promise runs the button shows a Spinner; done, the line strikes through and fades to muted and a toast says so, with Undo that calls `onRestore` (the line offers Restore too). A rejected revert marks the line "Couldn't revert" with the Error's message, and Try again. Revert run and ⌘Z (Ctrl+Z off Apple; `shortcut="document" | "log" | "off"`) revert what is left of the newest run, newest action first. `reverted` and `expanded` are controlled or not; `changes` (AgentSuggestionChanges) and `description` serve agents outside code. Parts: `AgentActionLogRoot`, `AgentActionLogRun`, `AgentActionLogAction`. Its words (`actionLog…`, `undo`) are translated with SatinLabels.
