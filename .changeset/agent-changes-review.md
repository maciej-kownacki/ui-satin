Reviewable changes (`@uisatin/pro/agent-changes-review`), an AI pattern: the fields an agent wants to change, each accepted or rejected before any is applied. It takes the same `changes` as AgentSuggestionChanges and draws each as a bordered card: the field's name on top in medium weight, then the old value struck through, an arrow and the new one, with Accept and Dismiss as bordered icon buttons at the end of that row. Accept's check is green; it is a toggle (pressing it again makes the card pending), and an accepted card's border turns green. Dismiss (X) slides the card out to the start while it fades, then moves the cards under it up into its place with a transform (no height animation; under reduced motion the card simply goes) and moves focus to the next card or the footer. Or a Checkbox before each card's name (`control="checkbox"`), where a cleared card stays and its value fades to text/muted. Then Accept all and Apply ("Apply 2 changes"). `onApply` gets the accepted changes only; a promise holds the applying stage (rows locked, Spinner), then Apply says Applied and each applied card gets a check. Controlled or not (`value` / `defaultValue` / `onValueChange`), with parts (`ReviewableChangesRoot`, `ReviewableChangesList`, `ReviewableChangesAcceptAll`, `ReviewableChangesApply`) to put Apply in AgentSuggestion's actions. Each card is a group named by its field and its buttons are named after the change ("Accept Stage change", "Dismiss Stage change"). Its words (`acceptFieldChange`, `rejectFieldChange`, `applyFieldChanges`, `applyingFieldChanges`, `fieldChangesApplied`, `fieldChangeApplied`, `fieldChangeNotApplied`, `allFieldChangesAccepted`, `fieldChangeRejected`) are translated with SatinLabels.
