Reviewable changes (`@uisatin/pro/agent-changes-review`), an AI pattern: the fields an agent wants to change, each accepted or rejected before any is applied. It takes the same `changes` as AgentSuggestionChanges and draws them the same way, with Accept on each row (a toggle; pressing it again makes the row pending) and Reject (X), which slides the row out to the start while it fades, then moves the rows under it up into its place with a transform (no height animation; under reduced motion the row simply goes) and moves focus to the next row or the footer. Or a Checkbox per row (`control="checkbox"`), where a cleared row stays and its value fades to text/muted. Then Accept all and Apply ("Apply 2 changes"). `onApply` gets the accepted changes only; a promise holds the applying stage (rows locked, Spinner), then Apply says Applied and each applied row gets a check. Controlled or not (`value` / `defaultValue` / `onValueChange`), with parts (`ReviewableChangesRoot`, `ReviewableChangesList`, `ReviewableChangesAcceptAll`, `ReviewableChangesApply`) to put Apply in AgentSuggestion's actions. Each row is a group named by its field and its buttons are named after the change ("Accept Stage change"). Its words (`acceptFieldChange`, `rejectFieldChange`, `applyFieldChanges`, `applyingFieldChanges`, `fieldChangesApplied`, `fieldChangeApplied`, `fieldChangeNotApplied`, `allFieldChangesAccepted`, `fieldChangeRejected`) are translated with SatinLabels.
