Reviewable changes (`@uisatin/pro/agent-changes-review`), an AI pattern: the fields an agent wants to change, each accepted or rejected before any is applied. It takes the same `changes` as AgentSuggestionChanges and draws them the same way, with Accept and Reject on each row (toggle buttons; pressing the pressed one makes the row pending again) or a Checkbox (`control="checkbox"`), then Accept all and Apply ("Apply 2 changes"). A rejected value fades to text/muted. `onApply` gets the accepted changes only; a promise holds the applying stage (rows locked, Spinner), then Apply says Applied and each applied row gets a check. Controlled or not (`value` / `defaultValue` / `onValueChange`), with parts (`ReviewableChangesRoot`, `ReviewableChangesList`, `ReviewableChangesAcceptAll`, `ReviewableChangesApply`) to put Apply in AgentSuggestion's actions. Each row is a group named by its field and its buttons are named after the change ("Accept Stage change"). Its words (`acceptFieldChange`, `rejectFieldChange`, `applyFieldChanges`, `applyingFieldChanges`, `fieldChangesApplied`, `fieldChangeApplied`, `fieldChangeNotApplied`, `allFieldChangesAccepted`) are translated with SatinLabels.
