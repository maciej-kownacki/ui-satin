CSV import (`@uisatin/pro/csv-import`): a CSV file into your records in three steps, Upload file › Map columns › Review, in one 600px panel whose steps row, footer and size stay put; only the step slides, with Satin's step slide. The steps row is an ordered list: the current step on the primary action's fill, done ones with a check, and any other step a button while it can be reached, back or forward as far as Next would go.

Upload file starts empty. The drop zone fills the step, and its picture is the file going into your app: a file tile, a dotted arrow that pulses toward the app (still under reduced motion), and the app's tile (`appIcon`, a database glyph by default). It takes a CSV only (`maxSize`, `templateHref`) and turns away Excel files (.xlsx and old .xls, renamed ones too) and binary files with the reason in an Alert. It reads UTF-8 with or without a BOM, UTF-16 by its BOM and Windows-1250 (Polish Excel exports), sniffs `,` `;` or tab (or honours Excel's `sep=` line), and handles quoted fields with escaped quotes and line breaks, in 8 ms slices so 10,000 rows never hold the page. An added file shows under the zone as an attachment whose bar fills while it is read; Next opens once it is, and nothing moves on by itself. `onBrowse` runs in place of the file picker and `dragging` shows the drag-over look, for demos and state sheets.

Map columns is one card, "Columns in your file → Lead fields": each column's name and first values, and a Select of your fields, each led by its type's icon, plus Don't import. Columns auto-match by key, label and `aliases`, ignoring case, diacritics, spaces, `-` and `_` ("E-mail" is Email, "Firma" is Company), and show a green check. A field mapped twice (both Selects are marked) or a required field with no column blocks Next with its reason as visible text, a Tooltip and `aria-describedby`; the button stays focusable. The card folds with the panel's width.

Review checks every row as the mapping changes (required, email, number in the locale's format, dd.mm.yyyy / yyyy-mm-dd / `dateFormat`, enum by label or value, then `validate`). It opens with two tiles, "328 Leads will be imported" and "12 Rows with errors", the second a toggle that shows only the rows with errors, then the rows, 100 a page. `maxRows` reports the rows past it instead of cutting them silently. Nothing is sent before "Import 328 leads" (`noun`): `onImport` gets only the valid rows, normalised, with `signal` and `onProgress`, and `cancelable` adds Cancel. The result's title says the outcome ("Import complete", "Import stopped", "Nothing was imported") and takes focus, over a table (`CsvImportResult`) with Imported and Skipped segments (Skipped gives each row's reason) and "Download skipped rows" (a CSV with an `error` column); "Import another file" starts over and `onDone` adds Done. A failed or cancelled run ends there too, as stopped, with Retry resuming after the last `onProgress` count (one reported after Cancel included), so no saved row is sent twice.

A `file` given from the start opens on Map columns once it is read, and a new one given later starts on Upload file; file and mapping work controlled or uncontrolled, and `onStepChange` reports the step on screen. `inDialog` makes each step's title and description the Dialog's name and description. Parts: `CsvImportMapping`, `CsvImportPreview`, `CsvImportProgress`, `CsvImportResult`; plain functions in `@uisatin/pro/csv-import-parse`: `parseCsv`, `csvHeaders`, `matchColumns`, `checkCsvValue`, `validateCsv`, `parseCsvNumber`, `parseCsvDate`, `toCsv`. Its words are translated with SatinLabels, counts through `Intl.PluralRules` and `NumberFormat`.
