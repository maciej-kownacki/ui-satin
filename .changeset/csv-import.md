CSV import (`@uisatin/pro/csv-import`): a CSV file into your records in three steps, Upload › Map columns › Review, in one panel whose Stepper, footer and size stay put; the steps change with Satin's step slide and nothing else moves. Upload takes a CSV only (`maxSize`, `templateHref`) and turns away Excel files (.xlsx and old .xls, renamed ones too) and binary files with a reason in an Alert; it reads UTF-8 with or without a BOM, UTF-16 by its BOM and Windows-1250 (Polish Excel exports), sniffs `,` `;` or tab (or honours Excel's `sep=` line), and handles quoted fields with escaped quotes and line breaks, in 8 ms slices so 10,000 rows never hold the page. Map columns auto-matches each column by key, label and `aliases`, ignoring case, diacritics, spaces, `-` and `_` ("E-mail" is Email, "Firma" is Company), with an Auto-matched Badge, sample values, "First row is a header" and a "Maps to" Select per column; a field mapped twice or a required field with no column blocks Next with its reason as visible text, a Tooltip and `aria-describedby` (the button stays focusable). Review checks every row (required, email, number in the locale's format, dd.mm.yyyy / yyyy-mm-dd / `dateFormat`, enum by label or value, then `validate`), says "340 rows · 328 ready · 12 with errors", groups errors by field in an Alert whose links jump to the first invalid cell, and previews 100 rows a page. Nothing is sent before "Import 328 leads" (`noun`); `onImport` gets only the valid rows, normalised, with `signal` and `onProgress`; `cancelable` adds Cancel, and the import ends in a result table (`CsvImportResult`): Imported and Skipped segments (Skipped gives each row's reason), "Download skipped rows" (a CSV with an `error` column) and "Import another file" (`onDone` adds Done). A failed or cancelled run ends there too, as stopped, with Retry resuming after the last `onProgress` count, so no saved row is sent twice; when nothing was imported the table body shows an empty state with the reason and Retry. `maxRows` reports the rows past it instead of cutting them silently. Step, file and mapping work controlled or uncontrolled; `defaultStep="map"` with a `file` skips Upload. Parts: `CsvImportMapping`, `CsvImportPreview`, `CsvImportProgress`, `CsvImportResult`; plain functions in `@uisatin/pro/csv-import-parse`: `parseCsv`, `csvHeaders`, `matchColumns`, `checkCsvValue`, `validateCsv`, `parseCsvNumber`, `parseCsvDate`, `toCsv`. Its words are translated with SatinLabels, counts through `Intl.PluralRules` and `NumberFormat`.
