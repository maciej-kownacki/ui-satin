Rich text editor (`@uisatin/pro/rich-text-editor`), first part: a field with Textarea's look for headings, lists, quotes, links, bold, italic, strikethrough, inline code and @mentions, on Lexical. Lexical is an optional peer (`lexical` and `@lexical/{rich-text,list,link,markdown,history}` at `~0.53.0`), and the editor is exported only from its own entry, never from `@uisatin/pro`. `value` is markdown (mentions as `[@Tara Mendes](mention:tara-id)`) or Lexical's JSON (`format="json"`), controlled or not; `onValueChange(value, { mentions })` fires only for edits, and a value the editor sent itself never reloads the document. Pasted text keeps bold, italic, links and lists and drops underline. Label, hint, error, placeholder, `status` and `maxLength` (a count of the text), read-only and disabled, and FormField's label, error, `required` and `name` (a hidden input). `editorRef` focuses, inserts markdown or text, reads the value and the selection's rectangle. Parts: `RichTextEditorRoot`, `RichTextEditorContent`. Its word (`richTextEditor`, the name when nothing else names it) is translated with SatinLabels. The toolbar and the @ and / menus come next.
