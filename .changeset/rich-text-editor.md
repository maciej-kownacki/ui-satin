Rich text editor (`@uisatin/pro/rich-text-editor`), first part: a field with Textarea's look for headings, lists, quotes, tables, links, bold, italic, strikethrough, inline code and @mentions, on Lexical. Lexical is an optional peer (`lexical` and `@lexical/{rich-text,list,link,markdown,history,table}` at `~0.53.0`), and the editor is exported only from its own entry, never from `@uisatin/pro`. `value` is markdown (mentions as `[@Tara Mendes](mention:tara-id)`, tables as GFM with a header row, Tab and Shift+Tab between cells, no table-editing controls) or Lexical's JSON (`format="json"`), controlled or not; `onValueChange(value, { mentions })` fires only for edits, and a value the editor sent itself never reloads the document. Pasted text keeps bold, italic, links and lists and drops underline. Label, hint, error, placeholder, `status` and `maxLength` (a count of the text), read-only and disabled, and FormField's label, error, `required` and `name` (a hidden input). `editorRef` focuses, inserts markdown or text, reads the value and the selection's rectangle. Parts: `RichTextEditorRoot`, `RichTextEditorContent`. A formatting toolbar inside the field (`toolbar`: text style menu, bold, italic, strikethrough, code, lists, quote, link; `'minimal'` or `false`) and a bubble over a pointer selection (`selectionToolbar`), pressed states following the selection; ⌘⇧X, ⌘E, ⌘⇧8, ⌘⇧7 and ⌘K besides ⌘B and ⌘I; a link popover under the selection that checks the address and adds https:// to a bare domain; ⌥F10 to the toolbar and Escape back. Parts `RichTextToolbar` and `RichTextSelectionToolbar` (with `actions`), items `RichTextBlockTypeMenu`, `RichTextFormatToggle`, `RichTextBlockToggle` and `RichTextLinkButton`. Its words (`richTextEditor`, `richTextToolbar`, `richTextBold` and the rest) are translated with SatinLabels. `mentions` (`{ trigger, search }`, Prompt bar's, with `avatar`) and `commands` open Prompt bar's menu under `@` or `/` at a block's start or after a space: ↑ ↓, Enter or Tab, Escape (taken only while the menu is open), an async search whose stale answers are dropped, a status region; a mention goes in as one unit with a space after it, a command's `run({ insert, editor })` inserts markdown where `/query` was. An input method's text never opens a menu.
